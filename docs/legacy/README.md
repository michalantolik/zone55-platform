# Legacy documentation archive

> **Legacy documentation:** Files in this directory are retained for historical reference and may describe earlier names, paths, or retired architecture.

The archive groups all former repository documentation under one root while preserving useful subfolders and relative links.

- `adr/` — architecture decision records
- `architecture/` — historical architecture notes and diagrams
- `learnkit/` — LearnKit migration and content notes
- `management/` — editorial workspace and smoke-test notes
- `infra/` — historical infrastructure notes
- `source/` — README files formerly stored beside source projects
- `tests/` — historical testing notes

Use the repository root [`README.md`](../../README.md) for the current solution layout and build instructions.
